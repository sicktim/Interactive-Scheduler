# Interactive-Scheduler
Interactive scheduler plus crew rainbow

**Live app:** https://sicktim.github.io/Interactive-Scheduler/

> **AI / LLM developers:** start with [`AI-CONTEXT.md`](./AI-CONTEXT.md) — a comprehensive,
> machine-oriented guide to the architecture, data contracts, all three views, and the
> feature nuances/gotchas this app encodes. It is written specifically so an AI coding
> assistant can replicate the features faithfully in another system (e.g. the TPS LMS).

As of **v4.3.0**, the refined standalone [TPS Crew Rainbow](https://github.com/sicktim/Schedule-Gantt)
(v6.3) has been merged into this app's Rainbow view — workload counters, today/now-line,
cancelled styling, person schedule modal, and pan-to-scroll, all driven by this app's single
data pipeline.
